An AI coding agent built a tiny browser game — **STARFALL** — from a single
prompt, while I watched. This repo is the entry for make.fun's
"post-x-the-agent-builds-a-game-from-20261122-1709" bounty: a short vertical
video of the prompt, the agent working, and the finished game running, posted

## The game

STARFALL: catch the falling stars in your basket. 60 seconds, 3 lives, combo
scoring. Move with mouse, touch, or arrow keys. One file, no dependencies:
open `game.html` in any browser and play.

## The video
